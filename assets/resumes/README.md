# Diretório de Currículos (`assets/resumes/`)

Coloque aqui os arquivos PDF do seu currículo formatados para ATS.

## Nomes Padrão Sugeridos:
- `curriculo_principal.pdf`: Versão primária utilizada pelo agente.
- `curriculo_backend.pdf`: Versão com ênfase em Backend / Engenharia de Software.
- `curriculo_fullstack.pdf`: Versão com ênfase em Fullstack.
- `curriculo_en.pdf`: Versão em inglês para vagas internacionais.
